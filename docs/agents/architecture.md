# Architecture

Read [the live architecture boundary](../concepts/architecture.rst) for the
canonical crate, persistence, replay, and observer contracts.

Rust owns four-week mechanics and authoritative PostgreSQL state. Bevy reads
authenticated observations and displays the administrative economy surface.
Python owns retained reference-data preparation and repository/operator tools.
The Python engine, mutable SQLite runtime, and their tests are retired; the
`p27-python-freeze` tag retains historical transcription evidence.

Use [NORTH_STAR.md](../../NORTH_STAR.md) for product direction and
[governance](governance.md) for contributor authority. Linear owns current work.
